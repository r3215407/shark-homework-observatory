# 鲨鱼观察站 H5

一个纯静态的手机网页应用，用于记录每天语文、数学、英语作业等级，并通过海洋生物卡片建立个人图鉴。数据保存在浏览器 `localStorage`，不需要后端或远程部署。

## 功能

- 每科可记录 A+、A、A-、B+、B、C 或“无作业”。
- 有效作业日根据等级获得 1-3 次海洋发现。
- 第一册包含 32 张普通卡和 16 张鲨鱼、鲸类及史前生物稀有卡。
- 普通卡可以升级到 `×2`、`×3 MAX`，稀有卡集齐前不重复。
- 已获得的海洋生物可以替换语文、数学和英语的科目头像。
- 支持历史补录、成绩分析、图鉴筛选和翻卡动效。

## 使用

在当前目录启动任意静态文件服务器，然后用手机浏览器打开服务器地址。手机和电脑需要连接同一个局域网。

也可以直接打开 `index.html`，但通过本地服务器访问时，浏览器存储和资源加载更稳定。

发送到手机时需要保留整个目录结构，至少包含 `index.html`、`styles.css`、`app.js`、`assets/` 和 `vendor/`。

## 数据

- 存储键：`shark-observatory-v1`
- 数据只保存在当前浏览器和当前访问地址中。
- 清除浏览器网站数据会同时清除作业记录、图鉴和科目伙伴。
